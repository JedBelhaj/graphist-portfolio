# Soltani Media & Marketing — Next.js front end

Marketing site for Soltani Media & Marketing (photo, video and campaign studio).

## Run

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` to read content from Sanity. Without it
the site renders the defaults below.

## Where the content lives

Text, photos, videos, logos, testimonials, team and packages are edited in
Sanity — see [`../studio`](../studio/README.md) for the admin and setup.

- `src/lib/cms.ts` — the one query the site makes, and how its result is
  merged over the defaults. Every component reads content through
  `getContent()`.
- `src/lib/content.ts` — the defaults: the original copy and placeholder
  imagery, shown wherever a Sanity field or list is empty (and seeded into
  Sanity by `npm run seed` in `../studio`). Photography still uses seeded
  [picsum](https://picsum.photos) placeholders until real photos are uploaded.
- `src/lib/brand.ts` — default name, contact details and handles, plus colour
  and type tokens (tokens stay in code).
- `sanity.types.ts` — generated by TypeGen from the studio schema; don't edit.
  Regenerate with `npm run typegen` in `../studio`.
- `src/components/Logo.tsx` — the wordmark (a fixed asset, not in the CMS).

`../design/` is the original Figma code export the layout was built from. It is
reference material and is intentionally left on the old branding.
